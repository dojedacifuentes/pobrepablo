# Decisiones de arquitectura (ADR)

Un archivo corto por decisión: contexto, decisión, consecuencias y cuándo se revisa. Una decisión aceptada no se
reescribe: si cambia, se agrega un ADR nuevo que la reemplaza y se anota aquí.

Las decisiones cerradas de origen (sin backend, stack, moneda, fechas, idioma, despliegue) no tienen ADR: están en
`docs/ESPECIFICACION.md` §1 y resumidas en `CLAUDE.md`.
